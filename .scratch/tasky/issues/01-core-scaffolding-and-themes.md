# 01: Core Scaffolding, Design System & Theming Foundation

**What to build:**
A robust, clean React + Vite + TypeScript application configured with Tailwind CSS, shadcn/ui components (Radix primitives, Lucide React), and a multi-theme provider supporting 7 themes (Modern Dark, Minimalist Light, Slate, Midnight Navy, Zinc, Cyberpunk Violet, Monokai). Includes application layout, navbar, theme switcher, and basic routing.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Initialize Vite + React 19 + TypeScript with strict compiler checks
- [ ] Configure Tailwind CSS with CSS variable tokens for light, dark, and custom themes
- [ ] Implement ThemeProvider with local storage persistence and instantaneous theme switching
- [ ] Install and configure core shadcn/ui primitives (Button, Card, Dialog, DropdownMenu, Tabs, Badge, Input, Tooltip, Sonner)
- [ ] Implement responsive top navigation bar with branding, theme selector, and user status placeholder
- [ ] Verify clean build with `npm run build`
